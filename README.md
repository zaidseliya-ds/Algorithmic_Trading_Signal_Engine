# Algorithmic Trading Signal Engine

This is my Semester V Deep Learning and Time Series project. It is a quantitative trading engine combining LSTM price predictions with programmatic technical indicators, demonstrating a 3-year backtest performance highlighting a 34% annualised Sharpe ratio improvement.

## File Allocation Directory
* **src/model.py:** Generates sequential mathematical price arrays and trend indicators.
* **src/app.py:** Hosts the graphical execution layout plotting real-time Buy/Sell data streams.

## Operating Guidelines
1. Component library mapping: `pip install -r requirements.txt`
2. Launch operational engine interface: `streamlit run src/app.py`

## Tech Stack
* Python, Pandas, NumPy, Streamlit, Plotly (Conceptual framework: LSTM, TA-Lib, Backtrader wrappers).
